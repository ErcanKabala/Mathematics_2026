## Exercise 7: Using Properties Instead of Recomputing

Given a $3 \times 3$ matrix with $\det A = -4$:[cite: 11]

* $\det(2A) = 2^3 \det A = 8 \cdot (-4) = -32$.[cite: 11] (Property: $\det(cA) = c^n \det A$).[cite: 11]
* $\det(A^T) = \det A = -4$.[cite: 11] (Property: Transposing doesn't change the determinant).[cite: 11]
* $\det(A^2) = (\det A)^2 = (-4)^2 = 16$.[cite: 11] (Property: $\det(AB) = \det A \det B$).[cite: 11]
* $\det(-A) = (-1)^3 \det A = -1 \cdot (-4) = 4$.[cite: 11]
