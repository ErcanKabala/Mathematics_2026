## Exercise 3: When Can Matrices Be Multiplied?

*Rule: For matrix multiplication to be defined, the number of columns in the first matrix must match the number of rows in the second matrix.*

* $AB$: Defined. Size: $2 \times 4$
* $BA$: Undefined (4 columns $\neq$ 2 rows)
* $BC$: Defined. Size: $3 \times 2$
* $CB$: Defined. Size: $4 \times 4$
* $AC$: Undefined (3 columns $\neq$ 4 rows)
* $CA$: Defined. Size: $4 \times 3$
* $AD$: Undefined (3 columns $\neq$ 2 rows)
* $DA$: Defined. Size: $2 \times 3$
